# ML и нейросети · 4 курс

Учебные реализации на Python без внешних зависимостей.

- [Линейная регрессия](linear_regression.py) обучается градиентным спуском и предсказывает числовые значения.
- [Персептрон](perceptron.py) решает задачу бинарной классификации и обновляет веса после каждого ошибочного предсказания. Для сходимости классы должны быть линейно разделимы.
- [Сигмоида](sigmoid.py) преобразует линейную оценку в число от 0 до 1. В логистической регрессии это вероятность класса `1`, а `predict` присваивает класс `1` при вероятности от `0.5`.

Запустите нужный пример из корня проекта.

```powershell
python -X utf8 linear_regression.py
python -X utf8 perceptron.py
python -X utf8 sigmoid.py
```

Команда `python -X utf8 ml_algorithms.py` запускает все примеры подряд.

У каждой модели `fit(X, y)` принимает матрицу признаков и вектор ответов, а `predict(X)` возвращает предсказания. Для классификации используются метки `0` и `1`. У `LogisticRegression` метод `predict_proba(X)` возвращает вероятность класса `1` для каждого объекта. Функцию `sigmoid(z)` можно вызывать отдельно.
