# Бинарное дерево поиска и статистика по тексту

Независимый от [postfix](../postfix) проект.

- [BinaryTree.hpp](include/BinaryTree.hpp) — бинарное дерево поиска (BST) без балансировки: `find` (поиск по ключу), `operator[]` (поиск существующего узла или вставка нового), `inorderTraversal` (обход в порядке возрастания ключей).
- [main.cpp](src/main.cpp) — читает текстовый файл, разбивает его на слова (регистронезависимо, с поддержкой кириллицы в UTF-8), строит на дереве статистику встречаемости слов (ключ — слово, значение — счётчик), затем даёт найти конкретное слово поиском по дереву.
- [sample.txt](sample.txt) — тестовый текст для демонстрации.

## Пример работы

```
Путь к текстовому файлу (пусто — sample.txt):

Всего слов: 56
Уникальных слов: 36

Частота слов (по алфавиту):
  and: 2
  ...
  лиса: 3
  ...

Найти слово (поиск в дереве, пусто — пропустить): Лиса
"лиса" встречается 3 раз
```

## Сборка и запуск в VS Code

Задачи в `../.vscode/tasks.json` и `../.vscode/launch.json`:

- **cmake: build (bst)** — собирает `build/bst/bst/bst.exe`.
- **run: bst** (`Ctrl+Shift+P` → `Tasks: Run Task`) — соберёт и запустит программу (рабочая директория — `bst/`, поэтому пустой ввод пути к файлу подхватит `sample.txt`).
- Конфигурация отладки **bst: debug** (F5, если выбрана в выпадающем списке конфигураций) — отладка через gdb прямо во встроенном терминале VS Code.

## Сборка вручную

```bash
cmake -S . -B build/bst -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug
cmake --build build/bst -j
cd bst && ../build/bst/bst/bst.exe
```
