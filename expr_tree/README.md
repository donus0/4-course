# Дерево арифметического выражения

Построение дерева по инфиксной записи выражения. Операнды — одна цифра или одна буква, операции `+ - * / ^` и круглые скобки.

- [expression_tree.hpp](include/expression_tree.hpp) — узел дерева и класс `expression_tree`.
- [expression_tree.cpp](src/expression_tree.cpp) — построение дерева на двух стеках (стек операций и стек поддеревьев, по аналогии с методом Дийкстры), обходы дерева (прямой, симметричный, обратный), вывод дерева и вычисление значения.
- [main.cpp](src/main.cpp) — читает выражение, печатает дерево и три формы записи, спрашивает значения переменных и считает результат.

## Алгоритм

1. Операнд превращается в лист и кладётся в стек поддеревьев.
2. `(` кладётся в стек операций.
3. `)` — из стека снимаются операции до `(`, из каждой собирается узел.
4. Операция — сначала собираются узлы из операций на стеке с большим приоритетом (или с равным, если операция левоассоциативная; `^` правоассоциативная), потом она сама кладётся в стек.
5. В конце собираются все оставшиеся операции, в стеке поддеревьев остаётся корень.

«Собрать узел» — снять операцию и два верхних поддерева, сделать операцию корнем, а поддеревья — левым и правым сыном.

## Пример работы

```
Введите выражение (пусто — выход), например (a+3)*b-5/c: (a+3)*b-5/c

Дерево (корень слева, правое поддерево сверху):

        c
    /
        5
-
        b
    *
            3
        +
            a

Префиксная форма:  - * + a 3 b / 5 c
Инфиксная форма:   ((a + 3) * b) - (5 / c)
Постфиксная форма: a 3 + b * 5 c / -

Введите значения переменных:
  a = 2
  b = 4
  c = 8

Значение выражения: 19.375
```

## Сборка и запуск

В VS Code: задача **run: expr_tree** или конфигурация отладки **expr_tree: debug**.

Вручную:

```bash
cmake -S . -B build/expr_tree -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug
cmake --build build/expr_tree -j
./build/expr_tree/expr_tree/expr_tree.exe
```
