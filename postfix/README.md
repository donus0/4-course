# Постфиксное преобразование выражений (метод Дийкстры)

Реализация на C++:

- [Stack.hpp](include/Stack.hpp) — стек на базе односвязного списка (шаблонный класс).
- [DynamicArray.hpp](include/DynamicArray.hpp) — динамический массив (ручная реализация), хранит элементы отсортированными и умеет дихотомический (бинарный) поиск (`binarySearch`) и вставку с сохранением сортировки (`insertSorted`).
- [InfixToPostfix.cpp](src/InfixToPostfix.cpp) — перевод инфиксного выражения в постфиксное по алгоритму Дийкстры (сортировочная станция). Операнды (числа и переменные) могут состоять из нескольких символов, поддерживаются `+ - * / ^` и скобки. Все встреченные операнды (входной массив) складываются в `DynamicArray<std::string>`.
- [PostfixEval.cpp](src/PostfixEval.cpp) — вычисление постфиксного выражения. Числа могут быть многозначными (в т.ч. дробными), токены разделяются пробелом.
- [main.cpp](src/main.cpp) — консольное меню для проверки обеих частей.

## Пример работы

```
Выбор: 1
Введите инфиксное выражение: (var+12)*c-9/x^2
Постфиксная форма: var 12 + c * 9 x 2 ^ / -
Операнды (входной массив, отсортирован): 12, 2, 9, c, var, x
Найти операнд дихотомическим поиском (пусто — пропустить): var
Найдено: "var" на позиции 4

Выбор: 2
Введите постфиксное выражение (токены через пробел): 12 3 4 * +
Результат: 24
```
