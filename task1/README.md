# Домашнее задание №1

Решения на Python для всех трёх заданий из `meta/Технология_сложных_систем_Задание_1.pdf`.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python task1.py   # сеточные функции
python task2.py   # численные и аналитические производные
python task3.py   # метод Эйлера для задач Коши
```

Графики сохраняются в `output/task1`, `output/task2`, `output/task3`.

## Содержание

- **task1.py** — для функций `e^(-x/2)`, `sin(3x)`, `cos^2(5x)` и `sum x^(2n)/(2n)!`
  строит сеточные функции на отрезках `[0; π/2]`, `[2; 10]`, `[-3; 3]` с шагом
  `h = 0.01, 0.005, 0.001` и сравнивает их с исходной функцией на графике.
- **task2.py** — для 5 заданных функций численно дифференцирует сеточные
  функции по формуле правой разности `y' ≈ (y[n+1]-y[n])/h` на отрезках
  `[0;1]`, `[2;15]`, `[-5;5]` с `h = 0.01, 0.005` и сравнивает результат с
  аналитической производной (вычисленной символьно через `sympy`).
- **task3.py** — явный метод Эйлера для 4 задач Коши (в т.ч. двух систем
  ОДУ 2-го порядка) на `[0; 10]` с шагом `h = 0.025`, с сопоставлением
  точному аналитическому решению.
