# Домашнее задание №2

Исследуется смещение груза на горизонтальной поверхности. В момент $t=0$ груз находится в положении равновесия пружины и получает скорость $v_0$. Во время скольжения

$$
mx''+hx'+kx=f(t)-\mu mg\,\operatorname{sign}(x'),
\qquad x(0)=0,\quad x'(0)=v_0.
$$

Пружина создаёт силу $-kx$, вязкое сопротивление равно $-hx'$, а сухое трение направлено против движения. При $\mu>0$ груз остаётся в покое, пока $|f(t)-kx|\leq\mu mg$. Если это неравенство нарушается, скольжение возобновляется в направлении силы $f(t)-kx$. Для трения покоя и скольжения используется один коэффициент $\mu$.

## Параметры

В расчётах $m=1$, $k=4$, $v_0=1$, $b=1$, $\omega=2$, $g=9.81$. Интервал времени составляет $[0,10]$, шаг численного метода — $0.005$. Для каждой силы $f(t)$ рассматриваются $\mu=0$ и $\mu=0.1$.

| Вязкое сопротивление | Свободное движение без сухого трения |
| --- | --- |
| $h=1$, $h^2<4km$ | Затухающие колебания |
| $h=5$, $h^2>4km$ | Возврат к равновесию без колебаний |

## Аналитическое и численное решения

Однородная часть решения определяется корнями $m\lambda^2+h\lambda+k=0$. Коэффициенты при экспонентах находятся из начальных значений смещения и скорости. К однородной части прибавляется частное решение $p(t)$ из таблицы.

| Внешняя сила $f(t)$ | Частное решение $p(t)$ |
| --- | --- |
| $0$ | $0$ |
| $t-1$ | $(t-1)/k-h/k^2$ |
| $e^{-t}$ | $e^{-t}/(m-h+k)$ при $h=1$. При $h=5$ число $-1$ является корнем характеристического уравнения, поэтому $p(t)=t e^{-t}/3$. |
| $b\sin(\omega t)$ | $\operatorname{Im}\bigl(b e^{i\omega t}/(k-m\omega^2+i h\omega)\bigr)$ |

На каждом участке скольжения к $p(t)$ добавляется постоянное смещение $-\mu mg\,\operatorname{sign}(x')/k$. Однородная часть определяется заново по состоянию в начале участка. На участке покоя $x$ постоянно, а $x'=0$. Границы участков уточняются бисекцией внутри шага по условию остановки или превышения предела трения покоя.

Численное решение получено методом Рунге–Кутты четвёртого порядка для системы $x'=v$ и $v'=(f(t)-kx-hv-\mu mg\,\operatorname{sign}(v))/m$ во время скольжения. При событии шаг разбивается, а оставшаяся часть рассчитывается с учётом нового состояния груза.

## Результаты

| Внешняя сила | Без сухого трения | При $\mu=0.1$ на интервале $[0,10]$ |
| --- | --- | --- |
| $0$ | При $h=1$ видны колебания вокруг нуля. При $h=5$ смещение после максимума убывает к нулю. | В обоих режимах груз останавливается на ненулевом смещении. Силу пружины уравновешивает трение покоя. |
| $t-1$ | После затухания переходного процесса смещение растёт почти линейно. | В обоих режимах груз останавливается, затем растущая сила снова приводит его в движение. |
| $e^{-t}$ | Внешняя сила затухает, и груз возвращается к равновесию. | При $h=1$ после первой остановки скольжение возобновляется один раз. При $h=5$ груз остаётся в покое после первой остановки. |
| $\sin(2t)$ | После затухания свободной составляющей груз колеблется с частотой внешней силы. | В обоих режимах видны несколько остановок и последующих возобновлений движения. |

Максимальное расхождение по смещению среди всех 16 расчётов составляет около $2.59\cdot 10^{-10}$. При уменьшении шага вдвое расхождение уменьшается примерно в 16 раз.
